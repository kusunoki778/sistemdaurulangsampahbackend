# Livora Frontend Design Guide

## 1. Referensi Desain

Desain frontend Livora Proyek 3 menggunakan desain Proyek 1 sebagai referensi awal dan dasar visual.

Desain Proyek 1 digunakan untuk mempertahankan identitas visual Livora, seperti:
- Warna utama
- Gaya typography
- Bentuk tombol
- Card
- Navbar
- Layout halaman
- Gaya penggunaan icon
- Gaya penggunaan gambar

Untuk fitur baru pada Proyek 3, desain dapat dikembangkan dari style yang sudah ada agar tampilan tetap konsisten.

---

## 2. Identitas Visual

### Brand
Nama aplikasi: **Livora**

Konsep visual:
- Lingkungan
- Daur ulang
- Edukasi
- Reward/gamifikasi
- Modern dan sederhana

### Warna Utama

Warna utama menggunakan nuansa hijau yang merepresentasikan lingkungan dan daur ulang.

Warna yang terlihat dominan:
- Hijau sebagai warna utama dan aksen
- Putih sebagai warna background/card
- Hitam atau dark gray untuk heading dan teks utama
- Hijau muda untuk background section
- Kuning/oranye untuk informasi koin
- Merah untuk aksi seperti Logout
- Biru/cyan digunakan sebagai warna pendukung pada icon atau kategori tertentu

Penggunaan warna harus tetap konsisten dan tidak terlalu banyak menggunakan warna dalam satu halaman.

---

## 3. Typography

Typography menggunakan gaya font modern, rounded, dan mudah dibaca.

Karakteristik:
- Heading besar dan tebal
- Subheading menggunakan ukuran sedang
- Body text lebih ringan dan nyaman dibaca
- Heading tertentu menggunakan kombinasi warna hitam dan hijau

Contoh penggunaan:
- "Wujudkan Bumi" → dark/black
- "Hijau" → green
- "Bersama" → dark/black

Heading dapat menggunakan kombinasi warna untuk memberikan penekanan pada kata tertentu.

---

## 4. Navbar

Navbar digunakan secara konsisten pada halaman utama website.

Struktur:
- Logo **Livora** di sebelah kiri
- Menu navigasi di sebelah kanan:
  - Beranda
  - Artikel
  - Tukar Sampah
  - Kontak
  - Logout
- Informasi jumlah koin di bagian paling kanan

Menu halaman aktif menggunakan:
- Background putih/abu muda
- Teks hijau
- Garis/border bawah hijau

Button koin menggunakan:
- Warna kuning/oranye
- Bentuk rounded/pill
- Icon koin
- Menampilkan jumlah koin pengguna

---

# 5. Halaman Beranda

Halaman Beranda memiliki beberapa section.

## 5.1 Hero Section

Hero menjadi bagian utama halaman.

Struktur:
- Heading besar
- Deskripsi singkat
- Dua CTA button
- Gambar bertema lingkungan/daur ulang

Contoh:
- "Wujudkan Bumi Hijau Bersama"
- Button "Mulai Tukar Sampah"
- Button "Pelajari Lebih Lanjut"

Gambar berada di sisi kanan dan menggunakan rounded corner.

Terdapat informasi reward/koin yang ditampilkan sebagai overlay pada gambar.

---

## 5.2 Mengapa Livora?

Section berisi penjelasan alasan menggunakan Livora.

Menggunakan 4 card:
1. Ramah Lingkungan
2. Misi Bersama
3. Peduli Bumi
4. Dapatkan Reward

Setiap card memiliki:
- Icon
- Judul
- Deskripsi
- Background putih
- Rounded corner
- Shadow tipis

---

## 5.3 Cara Kerja

Section menjelaskan proses penggunaan Livora dalam 4 langkah:

1. Pelajari & Pilah
2. Kumpulkan Sampah
3. Tukar dengan Koin
4. Dapatkan Reward

Setiap langkah ditampilkan dalam card dengan icon.

---

## 5.4 Dampak Positif

Section menampilkan statistik atau dampak penggunaan Livora.

Contoh informasi:
- CO₂ dikurangi
- Minyak jelantah terdaur
- Pohon diselamatkan
- Keluarga teredukasi

Setiap statistik ditampilkan dalam card dengan:
- Icon
- Angka utama
- Deskripsi
- Progress bar
- Persentase target

Card dapat menggunakan variasi background pastel.

---

## 5.5 Call To Action

Section CTA menggunakan background hijau.

Isi:
- Heading
- Deskripsi
- Button "Mulai Tukar Sampah"
- Button "Baca Artikel Edukasi"

CTA digunakan untuk mengarahkan pengguna ke fitur utama Livora.

---

## 5.6 Footer

Footer menggunakan background dark/black.

Struktur:
- Hubungi Kami
  - Telepon
  - Email
  - Alamat
- Telusuri
  - Tentang Kami
  - Tukar Sampah
  - Hubungi Kami
- Artikel Terbaru
  - Thumbnail artikel
  - Tanggal
  - Judul artikel

---

# 6. Halaman Artikel

Halaman artikel memiliki heading utama:

**Artikel Edukasi**

Terdapat deskripsi singkat mengenai artikel lingkungan.

Artikel ditampilkan menggunakan card.

Setiap card artikel memiliki:
- Gambar
- Kategori
- Tanggal
- Judul
- Deskripsi singkat

Kategori menggunakan badge/pill berwarna hijau.

Card menggunakan:
- Background putih
- Rounded corner
- Border/shadow tipis
- Gambar dengan rounded corner pada bagian atas

---

# 7. Detail Artikel

Halaman detail artikel digunakan untuk membaca artikel secara lengkap.

Struktur:
- Tombol/link kembali ke daftar artikel
- Judul artikel besar
- Badge kategori
- Tanggal
- Author/Admin
- Gambar utama artikel
- Isi artikel

Background menggunakan warna hijau muda.

Judul menggunakan ukuran besar dan bold.

---

# 8. Halaman Tukar Sampah

Halaman Tukar Sampah menjadi halaman utama untuk aktivitas pertukaran sampah.

Bagian atas:
- Heading "Tukar Sampah"
- Deskripsi singkat

Terdapat statistik pengguna:
- Total koin diperoleh
- Total sampah terkumpul
- Minyak jelantah terdaur
- Jumlah transaksi

Statistik ditampilkan dalam bentuk card.

---

## 8.1 Tab Tukar Sampah

Terdapat tiga tab:
- Nilai Tukar
- Reward
- Riwayat

Tab aktif menggunakan warna hijau dan garis bawah hijau.

### Nilai Tukar

Menampilkan daftar jenis sampah dan nilai tukarnya.

Contoh:
- Minyak Jelantah → koin per liter
- Kaleng Aluminium → koin per kilogram
- Kardus → koin per kilogram

Setiap item memiliki:
- Icon
- Nama jenis sampah
- Nilai tukar
- Button "Tukar"

---

## 8.2 Reward

Menampilkan daftar reward yang dapat ditukar menggunakan koin.

Reward menggunakan card yang berisi:
- Gambar
- Kategori
- Nama reward
- Deskripsi
- Stok
- Harga koin
- Button "Tukar"

Kategori reward dapat berupa:
- Tanaman
- Voucher
- Produk

---

## 8.3 Riwayat

Menampilkan riwayat transaksi koin pengguna.

Setiap transaksi menampilkan:
- Icon
- Nama transaksi
- Jenis transaksi
- Jumlah koin
- Tanggal transaksi

Transaksi positif dapat ditampilkan menggunakan warna hijau.

---

## 8.4 Popup Konfirmasi Reward

Ketika pengguna menekan tombol "Tukar", muncul popup/modal konfirmasi.

Isi popup:
- Tombol close
- Gambar reward
- Nama reward
- Kategori
- Harga reward
- Jumlah koin pengguna
- Sisa koin setelah penukaran
- Button "Batal"
- Button "Tukar Sekarang"

Tujuannya agar pengguna dapat memastikan transaksi sebelum diproses.

---

## 8.5 Popup Tukar Sampah

Fitur Tukar Sampah juga menggunakan popup/form untuk memasukkan data sampah.

Popup berisi input yang diperlukan untuk menentukan jenis dan jumlah sampah sebelum pengajuan pertukaran.

Pada Proyek 3, desain popup ini perlu disesuaikan dengan proses baru:
- Pemilihan jenis sampah
- Berat sampah
- Pengajuan
- Status verifikasi admin
- Hasil verifikasi
- QR/Barcode untuk klaim

---

# 9. Halaman Kontak

Halaman Kontak memiliki heading:

**Hubungi Kami**

Terdapat informasi kontak dan form.

Informasi kontak:
- Telepon
- Email
- Alamat

Form kontak:
- Nama Lengkap
- Email
- Nomor Telepon
- Subjek
- Pesan

Layout menggunakan dua sisi:
- Informasi kontak di sebelah kiri
- Form di sebelah kanan

Card menggunakan background putih dan rounded corner.

---

# 10. Halaman Login

Halaman Login menggunakan layout sederhana dan terpusat.

Komponen:
- Heading "Selamat Datang di Livora"
- Input Username
- Input Password
- Tombol Login
- Link "Lupa password?"
- Link "Lupa username?"
- Link "Daftar di sini"

Form berada dalam card putih dengan rounded corner dan shadow.

Button utama menggunakan warna hijau.

---

# 11. Halaman Registrasi

Registrasi merupakan halaman yang terhubung melalui link:

**"Belum punya akun? Daftar di sini"**

Desain registrasi harus mengikuti style halaman Login:
- Card terpusat
- Background hijau muda
- Input dengan rounded corner
- Button hijau
- Typography konsisten

---

# 12. Komponen UI

Komponen yang digunakan secara konsisten:

### Button
- Primary: hijau
- Secondary: putih/transparan dengan border
- Danger: merah
- Reward/Coin: kuning/oranye

### Card
- Background putih
- Rounded corner
- Shadow tipis
- Padding cukup
- Border tipis jika diperlukan

### Badge
Digunakan untuk:
- Kategori artikel
- Kategori reward
- Status

### Icon
Icon digunakan untuk memperjelas fungsi atau informasi.

Contoh:
- Coin
- Recycle
- Calendar
- Phone
- Email
- Location
- Reward
- Sampah

---

# 13. Prinsip Desain Proyek 3

Desain Proyek 3 tidak harus menyalin seluruh tampilan Proyek 1.

Proyek 1 digunakan sebagai **referensi visual utama**.

Prinsip yang dipertahankan:
- Identitas warna Livora
- Gaya typography
- Navbar
- Card
- Button
- Icon
- Rounded corner
- Layout bersih
- Nuansa lingkungan

Sedangkan fitur baru Proyek 3 dapat dibuat dengan komponen dan layout baru selama masih mengikuti visual identity Livora.

Fitur baru yang membutuhkan desain khusus pada Proyek 3:
- Daily Login
- Daily Quiz
- Daily Mission
- Weekly Mission
- Target sampah 2 kg/minggu
- Detail jenis sampah
- Pengajuan sampah
- Verifikasi sampah oleh admin
- QR/Barcode Claim
- Wallet/Koin
- Riwayat transaksi koin
- Notifikasi
- Chatbot
- Informasi lokasi dan jadwal pengumpulan

---

# 14. Catatan Frontend

Frontend Proyek 3 menggunakan:

- React
- Vite
- JavaScript

Struktur UI sebaiknya dibuat menggunakan reusable components agar tampilan antarhalaman konsisten.

Contoh component:
- Navbar
- Footer
- Button
- Card
- Modal
- Badge
- Input
- Tabs
- CoinBalance
- ArticleCard
- RewardCard
- WasteTypeCard
- TransactionCard
- StatisticCard

Desain harus responsive untuk desktop, tablet, dan mobile.
